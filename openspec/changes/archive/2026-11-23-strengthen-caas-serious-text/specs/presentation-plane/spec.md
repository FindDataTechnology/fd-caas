# Spec Delta

## ADDED Requirements

### Requirement: 严肃版式模板族

系统 SHALL 在 `render_document` 的版式目录中提供严肃文本模板族，至少覆盖公文
（GB/T 9704 版式）与学术（GB/T 7714、APA 引用格式）与通用报告三类。严肃版式 MUST 与既有
通用版式共用同一渲染底座与品牌主题，MUST NOT 为单一版式引入第二套渲染内核或第二套字体栈。
未知版式名 MUST 报错并列出可用版式。

#### Scenario: 按版式出稿

- **WHEN** 调用方以 `template=gongwen-gb9704` 渲染一份公文成稿
- **THEN** 产出符合该版式约定的分页文档
- **AND** 复用既有渲染底座与品牌主题

#### Scenario: 未知版式被拒

- **WHEN** 调用方指定一个不存在的版式名
- **THEN** 报错并列出可用版式清单
- **AND** 不产出任何部分产物

### Requirement: 引用锚点渲染为编号参考文献

当源文本含引用锚点（`[[cite:<id>]]`）且调用方指定引用格式时，`render_document` SHALL 把锚点
渲染为对应格式的编号参考文献，并在正文处以一致的编号回引。同一份源在不同引用格式下 MUST
产出各自格式正确的参考文献列表；无法解析的锚点 MUST 按「解不出即截断」处理，MUST NOT 渲染
出无出处的编号。

#### Scenario: 锚点渲成编号引用

- **WHEN** 一篇含 `[[cite:id]]` 锚点的源以 GB/T 7714 格式渲染
- **THEN** 文末产出编号参考文献列表，正文处以同号回引
- **AND** 每条编号可对上其引用记录

#### Scenario: 不同格式各自正确

- **WHEN** 同一源分别以 GB/T 7714 与 APA 渲染
- **THEN** 两份产物的参考文献列表各自符合所请求的格式
- **AND** 正文回引编号与各自列表一致

#### Scenario: 解不出的锚点不渲染出处

- **WHEN** 源中含一个无法解析到引用记录的锚点
- **THEN** 该锚点不被渲染为参考文献编号
- **AND** 不生成一条无出处的引用
